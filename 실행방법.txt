========================================
 🤗 토닥토닥 건강일기 — 실행 방법
========================================

이 폴더는 "토닥토닥 건강일기" 앱의 전체 소스 코드입니다.
식단·운동·수면·복약·체중을 기록하는 건강 관리 웹 앱입니다.
모든 기록은 사용자의 브라우저에만 저장되며 서버로 전송되지 않습니다.

----------------------------------------
방법 1. 그냥 바로 써보기 (제일 쉬움)
----------------------------------------
dist 폴더 안의 standalone.html 파일을 더블클릭하세요.
브라우저에서 앱이 바로 실행됩니다. 설치가 필요 없습니다.

----------------------------------------
방법 2. 개발자로 실행하기 (코드 수정용)
----------------------------------------
1) Node.js 설치 (https://nodejs.org — LTS 버전)
2) 이 폴더에서 명령 프롬프트(cmd)를 열고:

   npm install
   npm run dev

3) 브라우저에서 http://localhost:5173 접속

수정 후 배포용 빌드는:  npm run build  →  dist 폴더에 생성

----------------------------------------
폴더 구성
----------------------------------------
src/pages/        화면들 (홈·식단·복약·수면·추천·리포트·체중·설정)
src/components/   공용 부품 (캐릭터, 차트, 폼 등)
src/lib/          계산 로직 (칼로리·감량·운동 MET·수면)
src/data/         내장 데이터 (한식 109종, 운동 28종)
src/assets/       움직이는 캐릭터 SVG 8종
dist/             완성 빌드 (standalone.html = 단일 파일 버전)

기술: Vite + React 18 + TypeScript + Tailwind CSS + Dexie(IndexedDB)

자세한 내용은 README.md 를 참고하세요.
